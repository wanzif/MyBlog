## 前言：应急响应工具的重要性

在安全事件发生后，快速、准确地获取现场信息是应急响应的关键。Windows 系统作为企业最常见的操作系统，掌握其应急响应工具体系至关重要。

**应急响应核心目标：**

- 🔍 **发现异常** - 识别入侵痕迹和异常行为
- 📊 **保留证据** - 收集日志、内存、文件等关键证据
- 🛡️ **控制影响** - 阻止威胁扩散，保护关键资产
- 🔎 **追溯溯源** - 分析攻击路径，定位攻击来源

## 第二章：Sysinternals 工具集详解

Sysinternals 是 Microsoft 官方的 Windows 高级工具集，是应急响应的**必备工具包**。

### 2.1 Process Monitor（实时行为监控）

**功能**：实时监控文件系统、注册表、进程/线程活动

**下载地址**：[https://learn.microsoft.com/sysinternals/downloads/processmonitor](https://learn.microsoft.com/sysinternals/downloads/processmonitor)

**核心用途**：

- 🔍 恶意软件行为分析
- 🛠️ 软件问题排查
- 🔐 权限问题诊断
- 📊 应用程序行为审计

**常用命令行启动方式**：

```bash
# 后台监控并保存日志
procmon.exe /Minimized /Capture /BackingFile C:\Logs\capture.pml
# 加载配置文件启动
procmon.exe /LoadConfig filter.pmc /Capture
# 静默模式
procmon.exe /Quiet /AcceptEula /Capture
```

**关键过滤条件**：

```text
# 指定进程监控
Process Name is malware.exe → Include
# 失败操作监控（权限问题）
Result is ACCESS DENIED → Include
# 注册表监控
Path begins with HKLM\Software → Include
# 文件写入监控
Operation contains Write → Include
```

### 2.2 Process Explorer（进程分析）

**功能**：进程树、DLL、句柄、网络连接分析

**下载地址**：[https://learn.microsoft.com/sysinternals/downloads/processexplorer](https://learn.microsoft.com/sysinternals/downloads/processexplorer)

**核心用途**：

- 📊 查看进程父子关系
- 🔍 查看进程加载的DLL
- 📌 检测DLL注入
- 🌐 查看进程网络连接

**关键功能**：

| 功能 | 用途 |
|------|------|
| Process Tree | 进程父子关系追踪 |
| DLL View | DLL加载检测 |
| Handles View | 句柄分析 |
| Properties | 进程详细信息 |
| VirusTotal Check | 快速恶意检测 |

**与 Procmon 配合使用**：

```text
Process Explorer → 找到可疑进程
Process Monitor → 过滤该PID，分析行为
```

### 2.3 Autoruns（自启动项分析）

**功能**：全面扫描 Windows 所有自启动位置

**下载地址**：[https://learn.microsoft.com/sysinternals/downloads/autoruns](https://learn.microsoft.com/sysinternals/downloads/autoruns)

**核心用途**：

- 🔍 检测恶意持久化项目
- 📊 审计合法启动项
- 🛡️ 发现隐藏的启动项

**扫描位置（超过50个）**：

```text
启动项位置
├─ 注册表
│   ├─ HKLM\Software\Microsoft\Windows\CurrentVersion\Run
│   ├─ HKCU\Software\Microsoft\Windows\CurrentVersion\Run
│   ├─ HKLM\Software\Microsoft\Windows\CurrentVersion\RunOnce
│   ├─ HKLM\System\CurrentControlSet\Services
│   └─ WMI事件订阅
├─ 文件系统
│   ├─ Startup文件夹（用户/公用）
│   ├─ C:\Windows\Tasks
│   ├─ C:\Windows\System32\Tasks
│   └─ 浏览器扩展
├─ 其他
│   ├─ 计划任务
│   ├─ 服务
│   ├─ 驱动
│   ├─ Boot Execute
│   ├─ Image File Execution Options
│   └─ AppInit DLLs
```

**使用要点**：

```bash
# 以管理员身份运行
autoruns.exe -a
# 验证文件签名
View → Verify Code Signatures
# 隐藏合法Microsoft条目
Options → Hide Microsoft Entries
# VirusTotal检测
右键条目 → Check VirusTotal
```

### 2.4 ProcDump（进程内存dump）

**功能**：捕获进程内存dump

**下载地址**：[https://learn.microsoft.com/sysinternals/downloads/procdump](https://learn.microsoft.com/sysinternals/downloads/procdump)

**核心用途**：

- 💾 捕获崩溃进程内存
- 🔍 恶意进程内存分析
- 📊 应用程序问题诊断

**常用命令**：

```bash
# 按PID dump
procdump.exe -ma 1234 output.dmp
# 按进程名
procdump.exe -ma malware.exe output.dmp
# CPU异常时dump（CPU超过80%触发）
procdump.exe -ma -c 80 malware.exe output.dmp
# 条件持续5秒后才触发dump（避免瞬时抖动误触发）
procdump.exe -ma -s 5 -c 80 malware.exe output.dmp
# 连续dump 3次（每次触发条件满足时各dump一次）
procdump.exe -ma -n 3 -c 80 malware.exe output.dmp
```

**关键信息**：

| 列 | 说明 |
|----|------|

| PID | 进程ID |
| Protocol | TCP/UDP |
| Local Address | 本地地址端口 |
| Remote Address | 远程地址端口 |

### 2.6 Strings（字符串提取）

**功能**：从文件中提取可打印字符串

**下载地址**：[https://learn.microsoft.com/sysinternals/downloads/strings](https://learn.microsoft.com/sysinternals/downloads/strings)

**核心用途**：

- 🔍 从恶意文件提取关键信息
- 📌 发现隐藏的URL、IP、命令
- 📊 分析未知文件类型

**常用命令**：

```bash
# 提取所有字符串（默认4字符以上）
strings.exe malware.exe
# 指定最小字符长度
strings.exe -n 8 malware.exe
# 输出到文件
strings.exe -n 8 malware.exe > strings_output.txt
# 提取Unicode字符串
strings.exe -u malware.exe
```

### 2.7 Sigcheck（文件签名验证）

**功能**：验证文件数字签名，查询VirusTotal

**下载地址**：[https://learn.microsoft.com/sysinternals/downloads/sigcheck](https://learn.microsoft.com/sysinternals/downloads/sigcheck)

**核心用途**：

- 🔐 验证文件是否被篡改

**常用命令**：

```bash

sigcheck.exe -u C:\Program Files
```

## 第三章：网络分析工具

### 3.1 Wireshark（流量抓包分析）

**功能**：网络流量捕获与分析

**下载地址**：[https://www.wireshark.org/download.html](https://www.wireshark.org/download.html)

**核心用途**：

- 🌐 抓取网络流量
- 🔍 分析恶意通信内容
- 📊 解密协议通信

**应急响应场景**：

```text
场景一：分析恶意软件通信
1. 抓取流量：Capture → Start
2. 过滤IP：ip.addr == malicious_ip
3. 分析内容：右键 → Follow TCP Stream
4. 提取恶意数据

场景二：分析C2通信
1. 过滤端口：tcp.port == 4444
2. 查看通信模式
3. 分析心跳包特征

场景三：DNS异常分析
1. 过滤DNS：dns
2. 查看查询域名
3. 检测DNS隧道
```

**常用过滤规则**：

```text
# 按IP过滤
ip.addr == 192.168.1.100
# 按端口过滤
tcp.port == 443
# 按协议过滤
http || dns || ftp
# 按进程过滤（需配合其他工具）
# 通过TCPView找到PID和端口，Wireshark过滤端口
```

### 3.2 内置网络命令

**netstat**：网络连接状态

```bash
# 显示所有连接
netstat -ano
# 只显示已建立连接
netstat -ano | findstr ESTABLISHED
# 显示监听端口
netstat -ano | findstr LISTENING
# 查看特定端口
netstat -ano | findstr :443
# 持续刷新显示
netstat -ano 1
```

**关键信息解读**：

```text
Proto  Local Address           Foreign Address      State       PID
TCP    192.168.1.100:49152     203.0.113.50:443     ESTABLISHED 1234
│      │                       │                    │           │
│      本机IP和临时端口         远程地址端口          连接状态    进程ID
```

> 提示：`0.0.0.0:端口` 出现在 Local Address 且 State 为 LISTENING 时，表示该端口在所有网卡上监听；ESTABLISHED 状态下 Local Address 应为本机具体 IP。


## 第五章：内存取证工具

### 5.1 Volatility（内存分析框架）

**功能**：分析内存dump文件，提取关键信息

- 🦠 发现隐藏进程、Rootkit

**关键命令**：

```bash
# 查看进程列表
volatility -f memory.dmp --profile=Win10x64_19041 pslist
# 查看进程树
volatility -f memory.dmp --profile=Win10x64_19041 pstree
# 查看网络连接
volatility -f memory.dmp --profile=Win10x64_19041 netscan
# 查看DLL加载
volatility -f memory.dmp --profile=Win10x64_19041 dlllist
# 查看命令行历史
volatility -f memory.dmp --profile=Win10x64_19041 cmdscan
# 查看注册表
volatility -f memory.dmp --profile=Win10x64_19041 hivelist
# 查看密码哈希
volatility -f memory.dmp --profile=Win10x64_19041 hashdump
# 检测恶意代码
volatility -f memory.dmp --profile=Win10x64_19041 malfind
# 检测隐藏进程
volatility -f memory.dmp --profile=Win10x64_19041 psxview
```

```text
# 查看支持的Profile
volatility --info | grep Win
常见Profile：
```

### 6.2 内置日志命令

**wevtutil**：事件日志命令行工具

```bash
# 查看日志列表
wevtutil el
# 查询安全日志最近20条
wevtutil qe security /c:20 /rd:true /f:text
# 按事件ID查询
wevtutil qe security /q:"*[System[(EventID=4624)]]" /c:10 /f:text
# 导出日志
wevtutil epl security security.evtx
# 清除日志（需权限）

```

**PowerShell查询**：

```powershell
# 查询登录事件（最近24小时）
Get-WinEvent -FilterHashtable @{LogName='Security';ID=4624;StartTime=(Get-Date).AddHours(-24)} |
Select-Object TimeCreated,Id,Message

# 查询进程创建
Get-WinEvent -FilterHashtable @{LogName='Security';ID=4688} -MaxEvents 100 |
Select-Object TimeCreated,Message

# 查询登录失败（暴力破解检测）
Get-WinEvent -FilterHashtable @{LogName='Security';ID=4625} |
Select-Object TimeCreated,Message

# 查询所有登录类型10（远程桌面）
Get-WinEvent -FilterHashtable @{LogName='Security';ID=4624} |
Where-Object {$_.Message -match "Logon Type: 10"} |
Select-Object TimeCreated,Message
```

### 6.3 LogParser（日志分析工具）

```bash
LogParser.exe "SELECT * FROM C:\Logs\*.log WHERE Text LIKE '%error%'" -i:TEXTLINE
```

### 6.5 Sysmon（系统监视器，应急响应最重要的数据源）

**功能**：Sysinternals 出品的系统级日志服务，安装后持续记录进程、网络、文件、注册表等关键行为——是普通 Windows 日志覆盖不到的盲区。

**下载地址**：[https://learn.microsoft.com/sysinternals/downloads/sysmon](https://learn.microsoft.com/sysinternals/downloads/sysmon)

**为什么必须部署**：默认 Windows 安全日志不记录进程命令行、网络连接对应的进程、DLL 加载等关键信息。Sysmon 补齐这些后，应急时才能回答"这个进程是谁拉起的、连了哪个 IP、改了哪些注册表"。**建议在安全事件发生前就全网部署**，否则事发后无法回溯。

**安装与配置**：

```bash
# 默认配置安装（管理员权限）
sysmon64.exe -i
# 使用社区规则配置安装（推荐 SwiftOnSecurity 规则集）
sysmon64.exe -i sysmonconfig.xml
# 更新配置
sysmon64.exe -c sysmonconfig.xml
# 卸载
sysmon64.exe -u
```

> 推荐规则集：[https://github.com/SwiftOnSecurity/sysmon-config](https://github.com/SwiftOnSecurity/sysmon-config)（开箱即用，已过滤大量噪音）

**关键事件ID**（日志位置：`Microsoft-Windows-Sysmon/Operational`）：

| 事件ID | 含义 | 应急价值 |
|--------|------|----------|
| 1 | 进程创建（含完整命令行、父进程、Hash） | 追踪恶意进程来源 |
| 2 | 文件创建时间被修改 | 检测反取证（时间戳篡改） |
| 3 | 网络连接（进程级） | 定位 C2 通信进程 |
| 5 | 进程终止 | 还原进程生命周期 |
| 6 | 驱动加载 | 检测 Rootkit |
| 7 | 镜像（DLL）加载 | 检测 DLL 注入/劫持 |
| 8 | CreateRemoteThread | 检测进程注入 |
| 10 | ProcessAccess（进程访问） | 检测凭据窃取（如访问 lsass） |
| 11 | 文件创建 | 追踪落地文件 |
| 12-14 | 注册表创建/修改/重命名 | 检测持久化 |
| 15 | 创建替代数据流（ADS） | 检测隐藏文件 |
| 22 | DNS 查询（进程级） | 定位恶意域名请求进程 |
| 23 | 文件删除 | 检测反取证清理 |
| 26 | 文件删除检测（留存副本） | 恢复被删恶意文件 |

**查询 Sysmon 日志**：

```powershell
# 查询某进程的全部网络连接（事件ID 3）
Get-WinEvent -FilterHashtable @{LogName='Microsoft-Windows-Sysmon/Operational';ID=3} |
Where-Object {$_.Message -match "malware.exe"} |
Select-Object TimeCreated,Message

# 查询 lsass.exe 被访问记录（事件ID 10，凭据窃取检测）
Get-WinEvent -FilterHashtable @{LogName='Microsoft-Windows-Sysmon/Operational';ID=10} |
Where-Object {$_.Message -match "lsass.exe"} |
Select-Object TimeCreated,Message

# 查询 DNS 查询记录（事件ID 22）
Get-WinEvent -FilterHashtable @{LogName='Microsoft-Windows-Sysmon/Operational';ID=22} -MaxEvents 100 |
Select-Object TimeCreated,Message
```

## 第八章：恶意代码分析与威胁情报

当确认文件可疑后，需要进一步回答"它到底干了什么"。本章工具用于深度分析样本行为与验证威胁情报。

### 8.1 IDA Pro / Ghidra（静态逆向分析）

**功能**：反汇编可执行文件，阅读程序逻辑——不运行样本也能看清它要做什么。

**下载地址**：

- IDA Free（免费版）: [https://hex-rays.com/ida-free](https://hex-rays.com/ida-free)
- Ghidra（NSA 开源，完全免费）: [https://ghidra-sre.org](https://ghidra-sre.org)

**核心用途**：

- 🔍 查看导入函数（判断能力：联网？注入？加密？）
- 📊 分析关键字符串与代码交叉引用
- 🔐 还原加密算法与通信协议
- 🦠 提取 C2 地址、互斥体名等 IOC

**应急场景快速用法**：

```text
1. 拖入样本 → 等待自动分析完成
2. 先看 Imports 窗口：出现 CreateRemoteThread / VirtualAllocEx → 大概率有注入行为
3. 再看 Strings 窗口：找 http://、https://、IP 地址、注册表路径
4. 对可疑字符串按 X（交叉引用）→ 跳到使用它的代码位置
5. 重点关注 WinMain / DllMain 入口逻辑
```

> IDA Pro 是商业软件（价格昂贵），IDA Free 功能够应急入门；Ghidra 免费且支持反编译为类 C 代码，对不习惯读汇编的人更友好。

### 8.2 x64dbg（动态调试）

**功能**：动态运行并调试程序，观察真实执行流程——静态分析看不懂的加壳/混淆样本，跑起来看。

**下载地址**：[https://x64dbg.com](https://x64dbg.com)

**核心用途**：

- 🔍 单步跟踪恶意代码执行
- 📌 在关键 API 下断点（如 InternetOpen、CreateProcess）
- 💾 dump 内存中解密后的真实代码（脱壳）
- 📊 观察寄存器与内存变化

**应急场景快速用法**：

```text
1. 在隔离虚拟机中打开样本
2. 在常用 API 下断点：bp CreateRemoteThread、bp VirtualAlloc、bp WriteProcessMemory
3. F9 运行，断下后查看调用参数（堆栈中的目标进程、缓冲区地址）
4. 跟随内存缓冲区 → 右键 → Follow in Dump，常能看到解密后的配置（C2、密钥）
```

⚠️ **必须在隔离虚拟机中运行**，样本会在调试过程中真实执行恶意行为。

### 8.3 YARA（恶意特征匹配）

**功能**：用自定义规则描述恶意软件特征，批量扫描文件/内存——"给恶意软件画像，按图索骥"。

**下载地址**：[https://github.com/VirusTotal/yara](https://github.com/VirusTotal/yara)

**核心用途**：

- 🔍 用已知特征批量排查主机上的恶意文件
- 📊 对样本做家族归类（这个样本和哪个已知家族像）
- 🌐 配合威胁情报：下载公开 YARA 规则直接用于排查

**规则示例**：

```yara
rule Suspicious_PowerShell_Download
{
    meta:
        description = "检测 PowerShell 下载执行行为"
        author = "IR Team"
    strings:
        $s1 = "DownloadString" nocase
        $s2 = "IEX" nocase
        $s3 = "Invoke-Expression" nocase
        $s4 = "FromBase64String" nocase
    condition:
        2 of them
}
```

**常用命令**：

```bash
# 用规则扫描单个文件
yara64.exe rule.yar malware.exe
# 递归扫描目录
yara64.exe rule.yar C:\Users\ -r
# 扫描进程内存（配合 Volatility yarascan）
```

### 10.3 快速响应脚本示例

**一键收集脚本（PowerShell）**：

```powershell
# 应急响应一键收集脚本
# 输出目录
$outputDir = "C:\IR_Collection_" + (Get-Date -Format 'yyyyMMdd_HHmmss')
New-Item -ItemType Directory -Path $outputDir | Out-Null

# 1. 收集网络连接
netstat -ano | Out-File -FilePath "$outputDir\netstat.txt"
netstat -ano | findstr ESTABLISHED | Out-File -FilePath "$outputDir\netstat_established.txt"

# 2. 收集进程信息
tasklist /v | Out-File -FilePath "$outputDir\tasklist.txt"
Get-Process | Select-Object Name,Id,Path,StartTime | Export-Csv -FilePath "$outputDir\processes.csv" -NoTypeInformation

# 3. 收集服务信息
Get-Service | Where-Object {$_.Status -eq "Running"} | Select-Object Name,DisplayName,Status | Export-Csv -FilePath "$outputDir\services.csv" -NoTypeInformation

# 4. 收集启动项
Get-ItemProperty "HKLM:\Software\Microsoft\Windows\CurrentVersion\Run" | Out-File -FilePath "$outputDir\run_hklm.txt"
Get-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run" | Out-File -FilePath "$outputDir\run_hkcu.txt"

# 5. 收集用户账户
net user | Out-File -FilePath "$outputDir\users.txt"
net localgroup administrators | Out-File -FilePath "$outputDir\admin_users.txt"

# 6. 收集计划任务
Get-ScheduledTask | Where-Object {$_.State -eq "Ready"} | Select-Object TaskName,TaskPath,State | Export-Csv -FilePath "$outputDir\scheduled_tasks.csv" -NoTypeInformation

# 7. 收集日志
Copy-Item "C:\Windows\System32\winevt\Logs\Security.evtx" -Destination "$outputDir\"
Copy-Item "C:\Windows\System32\winevt\Logs\System.evtx" -Destination "$outputDir\"
Copy-Item "C:\Windows\System32\winevt\Logs\Application.evtx" -Destination "$outputDir\"
Copy-Item "C:\Windows\System32\winevt\Logs\Microsoft-Windows-PowerShell%4Operational.evtx" -Destination "$outputDir\" -ErrorAction SilentlyContinue

# 8. 收集Prefetch
Copy-Item "C:\Windows\Prefetch\*" -Destination "$outputDir\Prefetch\" -Recurse -ErrorAction SilentlyContinue

# 9. 收集最近修改的文件（24小时内）
Get-ChildItem C:\Users\ -Recurse -Include *.exe,*.dll,*.ps1,*.bat -ErrorAction SilentlyContinue |
Where-Object {$_.LastWriteTime -gt (Get-Date).AddHours(-24)} |
Select-Object FullName,LastWriteTime,Length |
Export-Csv -FilePath "$outputDir\recent_files.csv" -NoTypeInformation

# 输出完成
Write-Host "收集完成，输出目录: $outputDir"
```
