> 前两天刷到一篇公众号，讲怎么在 Mac 上把大模型跑在本地。看完觉得思路挺清楚，就想在自己 Windows 笔记本上复刻一遍——结果发现，步骤能对上，但"能跑多大模型"这件事，在两台机器上完全不是一回事。这篇把坑和原理都记下来，方便你也跟着做。

## 先搞清楚：本地大模型到底吃的是什么

模型不是凭空跑的。它得先加载进内存（或显存）才能推理，所以一台机器能跑多大的模型，取决于两件事：内存够不够，以及显卡能不能帮上忙。

这里 Mac 和 Windows 的差别最关键：

- **Mac 的 M 系列芯片用的是统一内存**——CPU 和 GPU 共用同一块内存。系统有多少 RAM，模型就能用多少。所以一台 16GB、32GB 的 Mac，跑起中等模型来很从容。
- **Windows 笔记本大多内存和显存是分开的**。有独立显卡（N 卡 / AMD）的话，模型优先塞进显卡的显存（VRAM），速度最快；没有独显，或者显存不够，就退回到内存 + CPU 跑，能跑，但慢，系统还会拿硬盘当临时内存，更卡。

一句话：Mac 看总内存，Windows 先看显卡显存，再看内存。

## 动手前，先看自己的机器

不用装任何软件，两分钟就能查完：

- **内存多大**：设置 → 系统 → 关于，看"已安装的内存 (RAM)"。
- **显卡显存多大**：任务管理器 → 性能 → GPU，右上角看"专用 GPU 内存"（比如 4GB / 6GB / 8GB）。
- **处理器**：同一页也能看到 CPU 型号。

粗略的参考（有独显时看显存，没独显看内存）：

- 8GB 左右：只能玩 3B~7B 的小模型，图个能对话。
- 16GB+：7B 流畅，可以试 14B。
- 32GB+：20B 往上也行，但别指望太快。

如果手头机器本来就紧巴，像我这台，老实说带不动大模型——知道流程就行，别硬上。学校机房或者有独显的机器再试。

## 装运行底座：Ollama

不管 Mac 还是 Windows，真正干活的是同一个东西——**Ollama**。它负责下载、加载、在本地跑模型，还顺手开一个本地接口给别的软件调用。

Windows 上比 Mac 还省一步，因为没有 Homebrew 这种前置：

1. 打开 ollama.com/download，下载 `OllamaSetup.exe`，双击装完。
2. 装好之后任务栏右下角会出现一个 🦙 图标，说明后台服务已经起来了。
3. 验证一下，打开命令提示符或 PowerShell：

```powershell
ollama --version
```

能出版本号就说明装好了。

顺带说 Mac 那边怎么做：装好 Homebrew 之后，终端里 `brew install --cask ollama` 就行，效果一样。两边后面用的命令完全互通。

## 选个模型，跑起来

装好 Ollama，下一步就是拉一个模型下来跑。命令两边一模一样：

```powershell
ollama run qwen2.5:7b
```

我这里用 `qwen2.5:7b`，原因很简单——它是现在真能下载到的、中文表现不错、7B 这个体量在大多数笔记本上都能跑起来的模型。常见可选项：

- `qwen2.5:7b` / `qwen2.5:14b`：中文、代码都稳，按机器选大小。
- `qwen3:8b`：新一代，体积和效果更均衡。
- `llama3.1:8b`：英文强，中文也够用。
- `deepseek-r1:7b`：想体验推理模型可以试。

第一次会下载模型文件，大小几个 GB，网速决定耗时。下到一半断了不用慌，**重跑同一条命令会自动续传**。

下载完 Ollama 会自动进对话模式，出现 `>>>` 提示符。先问一句最朴素的：

```text
你是谁？
```

能正常回，说明这条路通了。

## 不想敲命令行？上图形界面

命令行不是所有人的菜，两个更直观的选择：

- **Ollama 官方桌面 app**：下载时勾上就行，拖一拖、点一点就能聊天。命令行下过的模型会自动出现，不用重新下载。
- **Cherry Studio / Open WebUI**：这类工具能连到本地的 Ollama（默认地址 `localhost:11434`），给你一个更像聊天软件的界面，还能管理多个模型、做对话分组。

也就是说，Ollama 跑起来之后，它其实是你本地模型的统一入口，后面想接什么前端都行。

## 一点实在的收尾

这套东西的原理不复杂：先确认机器能吃多大的模型，再装 Ollama 当底座，最后按硬件挑一个跑得动的版本。Mac 和 Windows 的区别，主要就在"统一内存 vs 显存"和"用什么装 Ollama"这两点上，模型命令本身是通的。

我自己这台本子带不动，所以没真跑起来——流程记清楚，等换了合适的机器再动手也不迟。如果你手头有带独显的机器，照上面走一遍，半小时就能拥有个完全本地、不用联网、不花 token 的聊天模型。
