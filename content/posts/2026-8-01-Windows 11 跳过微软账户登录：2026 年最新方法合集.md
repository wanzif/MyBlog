安装完 Windows 11 新系统后，微软会强制要求登录微软账户才能继续。想用本地账户、不想绑云服务、或者装机环境根本没网——跳过这一步的理由很多。

微软和用户之间这场"猫抓老鼠"打了三年：24H2（2024 年下半年）封了虚假邮箱法，2025 年 3 月直接把最经典的 `oobe\bypassnro` 脚本从系统镜像里删了，25H2 又陆续堵上了好几个口子。但截至目前（2026 年 8 月），仍然有多条路可以走。

本文测试环境：**Windows 11 Insider Preview Build 29617**（中文版），部分方法兼容 24H2 / 25H2。

---

## 快速选择指南

| 你的情况 | 推荐方法 | 耗时 |
|---|---|---|
| 新装机，用 U 盘装系统 | 方法一：Rufus | 5 分钟 |
| 系统已开始安装，卡在登录页 | 方法二：WinJS 控制台 | 30 秒 |
| 提前准备了 .reg、Shift+F10 能用 | 方法三：注册表文件（双击导入） | 2 分钟 |
| 忘了准备 .reg、Shift+F10 还能用 | 方法四：reg add 命令补救 | 3 分钟 |
| 想一劳永逸、不怕折腾 | 方法五：无人值守文件 | 15 分钟 |
| 专业版/企业版/教育版用户 | 方法六：域加入 | 10 秒 |
| 以上全部失效 | 方法七：先登录再切 | 3 分钟 |

## 方法一：Rufus 制作定制安装盘（最彻底，推荐）

如果你是从 U 盘全新安装系统，直接从源头解决问题——让安装盘本身就不要求微软账户。

**步骤：**

1. 从 [微软官网](https://www.microsoft.com/software-download/windows11) 下载 Windows 11 ISO 镜像
2. 下载 [Rufus](https://rufus.ie/)（4.6 或更高版本，免费开源，无需安装）
3. 插入一个 8GB 以上的 U 盘（盘上数据会被清空）
4. 打开 Rufus → 选择你的 U 盘 → 点击「选择」加载 ISO
5. 点击「开始」，弹出「Windows 用户体验」对话框，勾选：
   - ☑ **移除对在线 Microsoft 账户的要求**
   - ☑ **使用用户名创建一个本地账户**（填入你想要的用户名）
   - ☑ **禁用 BitLocker 自动设备加密**（建议勾上，避免 BitLocker 恢复密钥丢失后数据无法找回）
6. 点击 OK，等待写入完成

用这个 U 盘安装 Windows 11，微软账户登录界面根本不会出现——直接进本地账户创建。

> 这是目前最干净的办法。一次操作，以后每次用这个 U 盘装机都自动跳过。


## 方法二：WinJS 开发者控制台（最新发现，Home 版可用）

这是 2025 年底被发现的新通道，来自 GitHub 项目 [WinJS-Microsoft-Account-Bypass](https://github.com/the-P1neapple/WinJS-Microsoft-Account-Bypass)。到 2026 年 8 月仍未被封——因为它走的不是命令行，而是 OOBE 内置的 JavaScript 调试接口。

**步骤：**

1. 走到「选择键盘布局」画面后，按 **Ctrl + Shift + J**（不是 Shift+F10）
2. 屏幕底部会弹出 WinJS 开发者控制台
3. 在控制台中输入以下命令，回车：

```javascript
WinJS.Application.restart("ms-cxh://LOCALONLY")
```

4. OOBE 会自动重启，直接跳转到本地账户创建画面

> 为什么还没被封？微软 2025 年 10 月的补丁主要针对 Shift+F10 命令行路径。WinJS 控制台是 OOBE 自身的 UI 框架调试接口，跟命令行是完全不同的入口。但按趋势，2026 年内大概率也会被堵上——趁还能用。


## 方法三：注册表文件（提前准备 .reg，装机时双击导入）

如果 WinJS 控制台也打不开，提前准备一个 .reg 文件是最稳妥的——不需要敲注册表命令，双击导入即可。

### 3.1 制作 .reg 文件

打开记事本，粘贴以下内容：

```
Windows Registry Editor Version 5.00

[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\OOBE]
"BypassNRO"=dword:00000001
"HideOnlineAccountScreens"=dword:00000001
"SkipMachineOOBE"=dword:00000001
"SkipUserOOBE"=dword:00000001

[HKEY_LOCAL_MACHINE\SYSTEM\Setup\Status\SysprepStatus]
"OOBEState"=dword:00000003
```

保存时注意：**文件名填 `xxx.reg`，保存类型选「所有文件 (*.*)」，编码选 UTF-16 LE**。如果保存后文件名是 `xxx.reg.txt`，说明保存类型没选对——需要开启「显示文件扩展名」（见附二）把 `.txt` 删掉。

### 3.2 装机时使用

1. 把 .reg 文件放在 U 盘根目录或本地 C 盘根目录（好找）
2. 安装系统
3. 在微软账户登录界面，按 Shift+F10 打开命令提示符，输入 `explorer` 回车
4. 此时会弹出文件资源管理器，找到那个 .reg 文件，双击导入（两次"是"）
5. 回到命令提示符，输入 `shutdown /r` 重启
6. 重启后即可创建本地账户

> 这四行注册表做了什么：`BypassNRO` 跳过联网要求，`HideOnlineAccountScreens` 隐藏在线账户界面，`SkipMachineOOBE` + `SkipUserOOBE` 跳过设备和用户的初始设置向导。下面的 `OOBEState = 3` 告诉系统"OOBE 已完成"。


## 方法四：reg add 命令补救（忘了准备 .reg 时的紧急方案）

如果你已经进入 OOBE 界面、手边没有另一台电脑来准备 .reg 文件——那就只能在命令提示符里一行一行敲了。

**步骤：**

1. 在登录微软账户的界面，按 **Shift + F10**（笔记本可能需要 Shift + Fn + F10）打开命令提示符
2. 逐行输入以下命令，每行回车：

```cmd
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\OOBE" /v BypassNRO /t REG_DWORD /d 1 /f
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\OOBE" /v HideOnlineAccountScreens /t REG_DWORD /d 1 /f
shutdown /r /t 0
```

3. 电脑重启后会重新走一遍 OOBE，这次联网界面下方会出现 **「我没有 Internet 连接」**
4. 点击它 → 「继续执行受限设置」→ 创建本地账户即可

> 注意只打了两条 `reg add`（而方法三的 .reg 文件里写了四行），因为 `BypassNRO` + `HideOnlineAccountScreens` 两条足以触发跳过逻辑。在命令行环境多敲一行就多一分打错的风险。


## 方法五：Autounattend.xml 无人值守文件（进阶，一劳永逸）

这个方法适合经常装机的用户——把本地账户信息写进一个 XML 文件，放在 U 盘根目录，Windows 安装程序会自动读取并跳过所有账户设置。

**步骤：**

1. 在 U 盘根目录新建 `autounattend.xml`，内容如下：

```xml
<?xml version="1.0" encoding="utf-8"?>
<unattend xmlns="urn:schemas-microsoft-com:unattend">
    <settings pass="oobeSystem">
        <component name="Microsoft-Windows-Shell-Setup" processorArchitecture="amd64" publicKeyToken="31bf3856ad364e35" language="neutral" versionScope="nonSxS" xmlns:wcm="http://schemas.microsoft.com/WMIConfig/2002/State" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance">
            <OOBE>
                <HideEULAPage>true</HideEULAPage>
                <HideOnlineAccountScreens>true</HideOnlineAccountScreens>
                <HideWirelessSetupInOOBE>true</HideWirelessSetupInOOBE>
                <SkipMachineOOBE>true</SkipMachineOOBE>
                <SkipUserOOBE>true</SkipUserOOBE>
            </OOBE>
            <UserAccounts>
                <LocalAccounts>
                    <LocalAccount wcm:action="add">
                        <Name>你的用户名</Name>
                        <DisplayName>你的显示名称</DisplayName>
                        <Group>Administrators</Group>
                        <Password>
                            <Value>你的密码</Value>
                            <PlainText>true</PlainText>
                        </Password>
                    </LocalAccount>
                </LocalAccounts>
            </UserAccounts>
        </component>
    </settings>
</unattend>
```

2. 把 `你的用户名`、`你的显示名称`、`你的密码` 改成自己的（若不想设密码，删掉 `<Password>` 整段）
3. U 盘插入电脑，正常安装 Windows 11
4. Windows 安装程序会自动检测 U 盘根目录的 `autounattend.xml`，按文件配置自动创建本地账户

> 这是企业 IT 批量部署的标准做法，微软不会封——封了就没人用 Windows Server 了。


## 方法六：域加入（专业版/企业版/教育版专用，10 秒搞定）

如果你用的是 Windows 11 专业版或更高版本，有个内置后门——不需要任何命令行操作。

**步骤：**

1. 在微软账户登录界面，点击 **「改为域加入」** 或选择 **「设置供工作或学校使用」**
2. 点击 **「登录选项」**
3. 选择 **「域加入」**
4. 直接输入本地用户名和密码创建账户

> Home 版没有这个选项，仅限 Pro / Enterprise / Education 版本。


## 方法七：事后补救——先登录微软账户，再切回本地账户

如果以上方法全部失效（极端情况），还有一个兜底方案：先妥协登录，进系统后再"断舍离"。

**步骤：**

1. 用微软账户完成登录，进入桌面
2. 打开「设置」→「账户」→「你的信息」
3. 点击 **「改用本地账户登录」**
4. 按提示输入当前微软账户密码验证身份
5. 设置本地账户的用户名和密码
6. 注销，用新本地账户重新登录

这样你的文件、设置都不会丢，但微软账户已经从系统中解绑。

> 缺点：微软账户会在云端留下一条设备绑定记录。如果你介意这点，优先用前面的方法。


## 历史方法（仅供参考，大概率已失效）

以下方法在 Windows 11 早期版本有效，放在这里方便还在用旧系统的朋友查找。当前 Insider Preview 29617 版本实测无效。

### ms-cxh:localonly 命令

在微软账户登录界面按 Shift+F10，输入 `start ms-cxh:localonly` 并回车，会弹出本地账户创建窗口。

- **24H2 及以前**：有效
- **25H2 build 26220.6772 及以后**：已封

### oobe\bypassnro 命令

在微软账户登录界面按 Shift+F10，输入 `oobe\bypassnro` 并回车，电脑重启后出现"我没有 Internet 连接"选项。

- **24H2 2025 年 3 月更新前**：有效
- **24H2 2025 年 3 月更新后**：脚本被微软从 System32\OOBE\ 目录删除，命令不再被识别

### 虚假邮箱法

登录微软账户时输入 `no@thankyou.com`，密码随便填。此邮箱会触发微软的本地账户创建流程。

- **24H2 起**：已封。微软不再将虚假输入转发到本地账户。


## 附一：如何建立 .reg 注册表文件

1. 打开记事本，复制以下内容：

```
Windows Registry Editor Version 5.00

[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\OOBE]
"BypassNRO"=dword:00000001
"HideOnlineAccountScreens"=dword:00000001
"SkipMachineOOBE"=dword:00000001
"SkipUserOOBE"=dword:00000001

[HKEY_LOCAL_MACHINE\SYSTEM\Setup\Status\SysprepStatus]
"OOBEState"=dword:00000003
```

2. 记事本里点击 **文件 → 另存为**
   - 选择保存位置
   - **文件名**：`xxx.reg`
   - **保存类型**：必须选「所有文件 (*.*)」——不能选「文本文档 (*.txt)」
   - **编码**：选 **UTF-16 LE**（Win10/11 推荐）或 ANSI（Win7/10 老系统）
   - 点保存

3. 如果保存后文件名显示为 `xxx.reg.txt`，说明保存类型选错了。需要先开启「显示文件扩展名」（方法见附二），然后把 `.txt` 删掉，只保留 `.reg` 后缀。

## 附二：如何在 Windows 中开启「显示文件扩展名」

不同 Windows 版本位置略有差异：

**Windows 10 / Windows 11：**
- 打开任意文件夹（比如"此电脑"）
- 顶部菜单点 **「查看」**
- 找到「显示」这一组
- 勾选 **「文件扩展名」**

**Windows 7 等旧版本：**
- 打开任意文件夹
- 顶部点 **「组织」→「文件夹和搜索选项」**
- 切换到 **「查看」** 选项卡
- 在高级设置中，取消勾选 **「隐藏已知文件类型的扩展名」**
- 确定

---

> 进系统后如果想绑定微软账户，可以随时在「设置 → 账户 → 你的信息」里登录——跳过强制关卡不等于永久放弃云功能，只是把选择权拿回自己手里。
