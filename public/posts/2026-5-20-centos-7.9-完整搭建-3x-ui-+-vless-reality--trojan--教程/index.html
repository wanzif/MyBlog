CentOS 7.9 完整搭建 3x-ui + VLESS Reality / Trojan 教程 含所有踩坑记录和多客户端订阅方法

================================================================================

一、前置准备

  • CentOS 7.9 云服务器（香港/海外节点）
  • 服务器公网 IP 和 root 密码
  • SSH 工具（Windows: Xshell/Termius/PowerShell，Mac: 自带终端）

连接：ssh root@你的服务器IP

================================================================================

二、系统更新 + 关闭 SELinux

⚠️ CentOS 默认开启 SELinux，会拦截面板和节点，必须先关！

yum update -y && yum install -y curl wget socat && setenforce 0 && sed -i 's/SELINUX=enforcing/SELINUX=disabled/g' /etc/selinux/config

验证：

getenforce
# 输出 Disabled 或 Permissive 就对了

================================================================================

三、安装 3x-ui 面板

bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)

脚本提示是否自定义配置，输入 y，设置：

  • 用户名：别用 admin，自定义一个
  • 密码：设复杂的
  • 端口：20000 以上，如 21568

不设置则默认：admin / admin / 2053

忘记设置？SSH 里查看：

x-ui    # 选 10 查看当前设置

================================================================================

四、升级内核 + 开启 BBR

⚠️ CentOS 7.9 默认内核 3.10 不支持 BBR！手动装 ELRepo 经常失败（仓库源装不上），必须用一键脚本。

wget --no-check-certificate https://github.com/teddysun/across/raw/master/bbr.sh
chmod +x bbr.sh && ./bbr.sh

提示重启输入 y，重启后验证：

uname -r                              # 应显示 5.x+
sysctl net.ipv4.tcp_congestion_control # 应输出 bbr

BBR 暂时搞不定不影响代理使用，只是速度稍慢。

================================================================================

五、防火墙放行端口

⚠️ CentOS 用 firewalld，不是 ufw！别用 ufw 命令！

firewall-cmd --permanent --add-port=21568/tcp   # 面板端口
firewall-cmd --permanent --add-port=443/tcp      # 节点端口
firewall-cmd --permanent --add-port=443/udp
firewall-cmd --permanent --add-port=80/tcp       # 证书申请
firewall-cmd --permanent --add-port=2096/tcp     # 订阅端口
firewall-cmd --reload

⚠️ 阿里云/腾讯云/AWS 还要去网页控制台安全组放行这些端口！

================================================================================

六、面板基础配置

浏览器访问 http://IP:端口，登录后：

  1. 语言改成中文
  2. 修改默认密码

================================================================================

七、添加 VLESS Reality 节点

入站列表 → 添加入站

基础配置：

  • 备注：随便写
  • 协议：vless
  • 端口：443
  • 其他保持默认

Stream 设置：

  • Transmission：tcp
  • Security：reality

Reality 设置：

  • 点 X25519 生成密钥对
  • uTLS Target / SNI：默认 www.amazon.com:443 就行
  • 其他全部默认

客户栏：

  • flow：选 xtls-rprx-vision-udp443（支持 UDP 443，功能更全）
  • ID（UUID）：自动生成，客户端要填的

Sniffing：开启，勾选 HTTP + TLS + QUIC + FAKEDNS

其他字段全部默认，不用动。

VLESS Reality 字段说明#

基础配置：

字段 含义
启用 开关
备注 节点名字
部署到 多服务器时选，单台不管
地址 监听地址，留空=监听所有
总流量 0.0 不限流量
到期时间 空=永不过期

客户栏：

字段 含义
Email 用户标识，随机生成的就行
ID (UUID) 核心凭证，客户端连接必须填
Reverse tag 反向代理，不用管
Subscription 订阅标签，不用管
Comment 备注，不用管
Total traffic 流量限制，0=不限
Expiry 过期时间
Decryption none，VLESS 标准
Encryption none，VLESS 标准

Reality 设置：

字段 含义
Show 调试信息，不用开
Xver PROXY protocol 版本，保持 0
uTLS Target 伪装目标网站，默认即可
SNI 伪装域名，跟 Target 一致
Max Time Diff 时间差限制，0=不限
Short IDs 客户端需匹配其中一个，自动生成
公钥 客户端配置要填
私钥 ⚠️ 只留服务器，绝不能泄露！
mldsa65 Seed/Verify 后量子密钥，不用管

flow 选择：

  • xtls-rprx-vision：标准模式，处理 TCP
  • xtls-rprx-vision-udp443：额外支持 UDP 443（HTTP/3/QUIC），推荐选这个

Sniffing 设置：

  • Enabled：开启
  • HTTP + TLS + QUIC + FAKEDNS：全部勾选
  • 其他不勾

================================================================================

八、添加 Trojan 节点（Clash 客户端推荐）

⚠️ VLESS Reality 和 Trojan 可以同时添加，但端口不能重复！比如 VLESS 用 443，Trojan 用 8443。

入站列表 → 添加入站

基础配置：

  • 协议：trojan
  • 端口：8443（避开已占用的 443）
  • 其他默认

Stream 设置：

  • Transmission：tcp
  • Security：tls

TLS 设置（无域名，IP 自签证书）：

字段 怎么填
SNI 留空（没域名不填）
uTLS chrome
ALPN 留空或 http/1.1
Reject Unknown SNI 不开（没域名会拦自己）
其他 默认

数字证书：先保存节点，然后 SSH 申请 IP 证书：

x-ui

选 18（SSL Certificate Management）→ 选 2（Let’s Encrypt for IP Address）

申请完后回到节点编辑页面，证书路径会自动填入。

然后放行 Trojan 端口：

firewall-cmd --permanent --add-port=8443/tcp && firewall-cmd --reload

⚠️ 云安全组也要放行 8443！

================================================================================

九、订阅设置（最关键的坑！）

⚠️ 这是最大的坑！3x-ui 有两套订阅端点，给不同客户端用的！

面板设置 → 订阅设置：

必须同时开启两个：

选项 作用 URI 路径
常规（JSON subscription） v2ray 客户端订阅 /sub/
Clash / Mihomo subscription Clash 客户端订阅 /clash/

两个都要开启！保存后重启面板：

x-ui restart

两套订阅链接的区别#

假设你的订阅 TOKEN 是 abc123：

客户端 订阅链接 说明
v2rayN / v2rayNG http://IP:2096/sub/abc123 /sub/ 路径
Clash Verge http://IP:2096/clash/abc123 /clash/ 路径

⚠️ 路径不同！/sub/ 给 v2ray 用，/clash/ 给 Clash 用，不能混用！

⚠️ /clash/ 路径不能改成跟 /sub/ 一样，否则格式冲突！

获取订阅链接：入站列表 → 点节点⋮ → 操作 → 复制订阅链接

================================================================================

十、客户端配置

10.1 v2rayN（Windows）#

  1. 复制 /sub/ 订阅链接
  2. v2rayN → 订阅 → 订阅设置 → 添加 → 粘贴链接
  3. 订阅 → 更新全部订阅
  4. 选中节点 → 设为活动服务器 → 开启系统代理

10.2 v2rayNG（Android）#

  1. 复制 /sub/ 订阅链接
  2. 打开 v2rayNG → 右下角 + → 从剪贴板导入
  3. 选中节点 → 连接

10.3 NekoBox（iOS/Mac）#

  1. 复制 /sub/ 订阅链接
  2. 添加 → 从剪贴板导入
  3. 选中节点 → 连接

10.4 Clash Verge Rev（Windows/Mac/Linux）#

⚠️ 必须用 /clash/ 订阅链接！用 /sub/ 的导入会失败！

  1. 复制 /clash/ 订阅链接
  2. Clash Verge → 配置 → 新建 → Remote → 粘贴链接
  3. 保存 → 选中配置 → 开启系统代理

如果 /clash/ 订阅导入还是失败，手动创建 Local 配置：

Clash Verge → 配置 → 新建 → Local → 编辑

VLESS Reality 节点模板：

mixed-port: 7890
allow-lan: false
mode: rule
log-level: info
dns:
  enable: true
  enhanced-mode: fake-ip
  nameserver:
    - 223.5.5.5
    - 119.29.29.29
  fallback:
    - 8.8.8.8
    - 1.1.1.1

proxies:
  - name: "vless-reality"
    type: vless
    server: 你的服务器IP
    port: 443
    uuid: 你的UUID
    network: tcp
    tls: true
    udp: true
    flow: xtls-rprx-vision-udp443
    servername: www.amazon.com
    reality-opts:
      public-key: 你的公钥
      short-id: 你的short-id
    client-fingerprint: chrome

proxy-groups:
  - name: "🚀 节点选择"
    type: select
    proxies:
      - vless-reality
      - DIRECT

rules:
  - GEOIP,CN,DIRECT
  - MATCH,🚀 节点选择

Trojan 节点模板：

mixed-port: 7890
allow-lan: false
mode: rule
log-level: info
dns:
  enable: true
  enhanced-mode: fake-ip
  nameserver:
    - 223.5.5.5
    - 119.29.29.29
  fallback:
    - 8.8.8.8
    - 1.1.1.1

proxies:
  - name: "trojan"
    type: trojan
    server: 你的服务器IP
    port: 8443
    password: 你的Password
    udp: true
    sni: 你的服务器IP
    skip-cert-verify: true
    client-fingerprint: chrome

proxy-groups:
  - name: "🚀 节点选择"
    type: select
    proxies:
      - trojan
      - DIRECT

rules:
  - GEOIP,CN,DIRECT
  - MATCH,🚀 节点选择

⚠️ Trojan 模板中 skip-cert-verify 必须为 true（IP 自签证书验证会失败）

10.5 Linux 客户端#

安装 xray：

bash <(curl -L https://github.com/XTLS/Xray-install/raw/main/install-release.sh) install

配置文件 /usr/local/etc/xray/config.json：

{
  "inbounds": [
    {"port": 10808, "listen": "127.0.0.1", "protocol": "socks", "settings": {"udp": true}},
    {"port": 10809, "listen": "127.0.0.1", "protocol": "http"}
  ],
  "outbounds": [
    {
      "protocol": "vless",
      "settings": {
        "vnext": [{"address": "你的服务器IP", "port": 443, "users": [{"id": "你的UUID", "encryption": "none", "flow": "xtls-rprx-vision-udp443"}]}]
      },
      "streamSettings": {
        "network": "tcp",
        "security": "reality",
        "realitySettings": {
          "serverName": "www.amazon.com",
          "publicKey": "你的公钥",
          "shortId": "你的short-id",
          "fingerprint": "chrome"
        }
      }
    }
  ]
}

启动：

systemctl start xray && systemctl enable xray

使用代理：

export https_proxy=http://127.0.0.1:10809
export http_proxy=http://127.0.0.1:10809
export all_proxy=socks5://127.0.0.1:10808

================================================================================

十一、批量一键部署（多台服务器）

保存为 deploy.sh：

#!/bin/bash
PORT=${1:-2053}
USER=${2:-admin}
PASS=${3:-admin}

yum update -y && yum install -y curl wget socat
setenforce 0 2>/dev/null
sed -i 's/SELINUX=enforcing/SELINUX=disabled/g' /etc/selinux/config

bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh) <<EOF
y
$USER
$PASS
$PORT
EOF

wget --no-check-certificate -O /root/bbr.sh https://github.com/teddysun/across/raw/master/bbr.sh
chmod +x /root/bbr.sh && bash /root/bbr.sh <<< "y"

systemctl start firewalld 2>/dev/null
firewall-cmd --permanent --add-port=${PORT}/tcp
firewall-cmd --permanent --add-port=443/tcp
firewall-cmd --permanent --add-port=443/udp
firewall-cmd --permanent --add-port=80/tcp
firewall-cmd --permanent --add-port=2096/tcp
firewall-cmd --reload

x-ui restart

echo "============================================"
echo "  部署完成！"
echo "  面板：http://$(curl -s ifconfig.me):${PORT}"
echo "  用户名：${USER}  密码：${PASS}"
echo "  ⚠️ 请 reboot 使 BBR 生效"
echo "  ⚠️ 云安全组放行端口：${PORT}、443、80、2096"
echo "============================================"

批量执行：

for IP in $(cat ips.txt); do
    scp deploy.sh root@$IP:/root/
    ssh root@$IP "bash /root/deploy.sh 21568 myadmin Mypass2026!"
done

十二、踩坑总结

坑 症状 解决
SELinux 没关 面板/节点装好了但连不上 安装前先 setenforce 0 + 修改配置
内核 3.10 BBR 开不了 用 bbr.sh 一键脚本，不要手动装 ELRepo
ELRepo 装不上 手动升内核失败 用 bbr.sh 脚本绕过
firewalld 用 ufw 命令报错 CentOS 用 firewall-cmd
云安全组 面板/节点/订阅都连不上 云控制台安全组放行端口
Clash 订阅导入失败 用了 /sub/ 链接 Clash 必须用 /clash/ 路径
v2ray 订阅导入失败 用了 /clash/ 链接 v2ray 必须用 /sub/ 路径
订阅链接只有一种格式 面板只开了一个订阅 常规和 Clash 两个都要开启
/clash/ 路径改成 /sub/ 格式冲突两个客户端都炸 保持默认，/sub/ 和 /clash/ 各管各的
Trojan 用 443 端口 跟 VLESS Reality 冲突 不同协议用不同端口
Trojan 证书验证失败 Clash 连不上 Trojan skip-cert-verify: true
Clash Local 配置没刷新按钮 本地文件无法自动刷新 改用 Remote 订阅，或手动编辑
私钥泄露 安全风险 重新点 X25519 生成新密钥

十四、协议对比

协议 防封锁 配置难度 客户端兼容 推荐场景
VLESS Reality ★★★★★ 中等 v2rayN/v2rayNG/Clash Meta 个人用、防封锁优先
Trojan ★★★★ 简单 所有客户端 多设备、Clash 用户

建议两个都加，v2ray 用 VLESS Reality，Clash 用 Trojan。
